# 博物馆教育研究

小学阶段博物馆与文化遗产教育资料工作台，服务“奇妙博物馆进校园”课程与图册。

网页包含年龄段、主题、研究类型、证据强度、应用状态、核验状态筛选，独立可分享详情路由、注释书目Markdown/HTML导出、核验事项、应用记录与版本历史。初始8条一手资料以2025—2026年研究与工具为主。

## 数据保存

- `workspace.json`为公开资料库。所有设备读取同一公开版本。
- 收藏和未发布草稿保存在当前浏览器，支持JSON备份与导入。页面明确提示保存范围。
- 编辑完成后，使用“提交公开更新”复制更新内容，在GitHub Issue提交。只处理仓库所有者提交的`[Research Sync]`更新；版本冲突或重复来源会停止发布，保留原资料。
- 公开提交包括笔记、核验和应用记录。提交前检查个人信息。浏览器中不保存GitHub令牌。

## 持续收集

GitHub Actions每周一01:17 UTC（北京时间上午09:17）查询OpenAlex，收集近370天三个主题中最新的候选，按标识、DOI、来源URL与题名去重。自动候选保持“待核验”，不生成未经核对的研究结论、证据评级或已应用记录。原文审读与实践建议由研究者补充。

任务可能因外部API、权限、调度或GitHub账户设置失败；真实结果见Actions与网站版本历史。仓库不活跃时计划任务可能被平台暂停。

## 发布

在仓库Settings → Pages中选择GitHub Actions，运行`Research library and GitHub Pages`工作流。网站主体没有外部字体、脚本和图片依赖。GitHub Pages的国内访问情况需要具体网络实测。

`index.html`为已构建的完整页面；`prepare-site.mjs`只复制网页和公开数据到部署目录。GitHub工作流会在更新后直接发布，不依赖提交触发下一次工作流。
